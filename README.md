# Ryad Saka — portfolio commercial

Portfolio React/Vite pensé comme un outil de conversion : il explique ce que le travail peut changer pour une activité, montre des univers de projets distincts et simplifie la prise de contact.

## Lancer en local

```bash
npm install
npm run dev
```

## Vérifier la version de production

```bash
npm run build
npm run preview
```

## Déployer sur Netlify

Le fichier `netlify.toml` est déjà configuré : commande de build `npm run build`, dossier publié `dist`. Les redirections couvrent toutes les routes React Router.

Avant publication, suivre la liste dans [`CONTENT_NEEDED.md`](./CONTENT_NEEDED.md), en particulier l’e-mail de contact et le raccordement du formulaire.
