# Contenu à compléter avant publication commerciale

Le site est volontairement construit sans chiffres, témoignages ou résultats client non vérifiés. Avant la mise en ligne, prévoir :

- **Notifications Netlify Forms** : après le premier déploiement, dans Netlify, ouvrir *Forms* → *Form notifications*, puis ajouter une notification e-mail vers `contact@ryadsaka.com` pour le formulaire `project-request`. C’est l’unique action nécessaire pour recevoir les demandes.
- **Brevo (optionnel)** : une intégration future peut être ajoutée côté fonction serveur si un jour un routage ou une séquence e-mail est nécessaire. Ne jamais placer une clé Brevo dans le frontend.
- **Portrait** : ajouter une photo de Ryad dans la section À propos (ou conserver le fallback graphique si le choix est de rester discret).
- **Visuels des études de cas** : exporter 2 à 4 captures de qualité par projet depuis les sites concernés ; les placer dans `public/projects/` puis les référencer dans les pages projet.
- **Liens à vérifier** : Vortex, Maison Saint-Jules, Heritage, Maison des Pyjamas, Emma.illustre et ZION sont renseignés selon les URLs disponibles. Vérifier qu’ils sont publics avant diffusion.
- **Données commerciales vérifiables** : si de vrais retours clients, délais ou résultats peuvent être publiés plus tard, les ajouter avec leur contexte — jamais sous forme de promesse générale.
- **Réseaux sociaux** : ajouter uniquement les profils que Ryad souhaite rendre publics.
- **Nom de domaine / Open Graph** : une fois le domaine choisi, renseigner `canonical`, URL Open Graph et image de partage dédiée.
